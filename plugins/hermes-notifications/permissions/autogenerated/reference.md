## Default Permission

Default permissions for the Hermes notifications plugin

#### This default permission set includes the following:

- `allow-ensurePermission`
- `allow-permissionState`
- `allow-notificationPermissionResult`
- `allow-upsert`
- `allow-finish`
- `allow-clear`
- `allow-clearAll`
